# Question 4: [Gameboard.java]
## My Approach

I don't think this question was complicated, if I understood it right it's fairly straightforward. Even though the question was about a 2D Array, the method required to create used a row index as an argument, meaning that nested for-loops weren't necessary. So all I did was make a variable to count points in a row using one for-loop, and then make a boolean variable and a different for-loop to check if all the colors were the same, if it remained true, then double the points.
